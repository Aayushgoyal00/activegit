# ActiveGit

**Git, at the speed you think.**

Review, stage and commit from one fast terminal window.

<br>

<img src="docs/screenshots/hero.png" alt="ActiveGit: file tree on the left, syntax-highlighted diff on the right" width="100%">

</div>

<br>

**See every change.** Side-by-side diffs with syntax and word-level highlighting.

**Stage exactly what you mean.** A file, a folder, or a single hunk.

**Stuck on the commit message?** `Ctrl+G` drafts one from your diff, with the AI model you choose.

**Hard to break.** Anything destructive asks first, and the last discard can be undone.

**Keyboard or mouse.** Every action has a key and a click target.

**Instant.** Opens in about 10 ms and never freezes while git works.

## Install

**macOS / Linux**

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/DevarshVasani/activegit/releases/latest/download/activegit-installer.sh | sh
```

**Windows**

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/DevarshVasani/activegit/releases/latest/download/activegit-installer.ps1 | iex"
```

## Use

```sh
activegit
```

`space` stage · `c` commit · `Ctrl+G` AI message · `P` push · `?` everything else
